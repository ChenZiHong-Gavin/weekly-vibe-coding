# Prompt for Pixel Cat Diffusion

```
从零训练一个 text2cat 小模型，再把它做成纯前端网页 demo，不要后端。

模型（另一个仓库 catdiff 里训练）：
1. 数据：9,900 只 Cool Cats 像素猫（24×24，补到 32×32），每只有脸、帽子、衣服三个标签；用模板把标签拼成英文句子，如 "a cat with a happy face, wearing a blue beret"。
2. 像素空间 DDPM：cosine schedule，eps 预测，EMA；UNet 带自注意力，在 16×16 和 8×8 两层用交叉注意力接一个从零训练的 4 层小 transformer 文本编码器；训练时随机丢掉句子，做 classifier-free guidance。
3. 颜色增强：原数据里每种帽子只有一两种颜色，训练时把帽子、衣服随机换色并同步改句子，让"蓝色"能套到任何物件上；留出一部分（物件，颜色）组合只用来测试。
4. 为了在没有 WebGPU 的浏览器里也能几秒出图，用小号模型（400 万参数），导出 ONNX，权重 int8 存储（约 4 MB），先验证 int8 不掉效果。

网页（apps/pixel-cat-diffusion，静态文件，onnxruntime-web）：
1. 首屏整屏是一只大猫脸马赛克，由几千个模型生成的小猫拼成：按颜色挑格子并染色，铺满视口，窗口变化时重排；悬停显示那只小猫的放大图。
2. 往下是精简的生成器：英文描述（逐词标出模型认不认识）、几个示例、"帮我拼一句"（脸 / 帽子+颜色 / 衣服+颜色 / 随机）、数量、步数、听话程度（guidance）、种子、生成按钮。
3. 在浏览器里跑 DDIM + CFG，优先 WebGPU，回退 WASM；每一步刷新画面，看猫从噪声里浮现；点一只猫下载 PNG，或下载整张。
4. 版式参考杂志封面：窄体大字、朱红点缀；不要讲解长文和页脚。布局由 Codex 出几版提案后挑一版实现。
```
