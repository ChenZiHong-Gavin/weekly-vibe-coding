# Prompt for Wake Up Call

```
写一个真实的闹钟网页，单文件 HTML，中文，移动端优先，手绘画风。
名字：Wake Up Call · 叫醒服务

不是游戏，不是模拟器。就是一个能用的闹钟：设一个真实的起床时间，选一个角色，
它用它自己的性格叫你。产品的全部差异化在于「每个角色有一份自己的响铃排程」。

1. 角色 = 排程（plan(now, target) 返回一串真实时间戳）
   - 新生儿：从现在起每 2-3 小时一次，一整夜，到起床时间为止
   - 家猫：比起床时间早约 1 小时开始，之后每隔 8-16 分钟来一次，一直到点
   - 蚊子：整夜随机 2-4 次，每次很短，加上起床时间
   - 公鸡：提前 40 分钟一次 + 准点一次
   - 大型犬：只在起床时间响一次
   - On-call 值班：半夜随机 1-3 次 + 准点一次
   短时间闹钟（比如 20 分钟后）要优雅降级成只响一次。

2. 关掉闹钟的方式也按角色不同
   - 新生儿：长按喂奶 → 再用滑块「轻轻放下」，推太快他会惊醒，前功尽弃
   - 家猫 / On-call：标记扫到区里时点击，命中 4 次
   - 蚊子：它随机出现 0.7 秒，拍它，四次机会；有三成概率这只永远拍不到
   - 公鸡：没有按钮，只能等它叫完
   - 大型犬：长按把它遛完
   设定前要能「试听一次」。

3. 三屏：设置（选角色 + 设时间 + 预览今晚会在几点响）→ 待机床头钟 → 响铃。
   每屏只有一个焦点，能一屏放下就别让人滚动。

3a. 设置页的核心是一张图：今晚的响铃时间轴。不要写成「今晚预计响 4 次 —— 23:44、
   02:22、07:00」这种句子，要画成手绘时间轴（横线 + 刻度 + 时间标签），让六个角色
   一眼可辨：猫是起床前挤成一簇，狗是末尾孤零零一根，新生儿整夜均匀铺开。起床那
   一刻用朱红加小铃铛标出，标签互相避让时它永远优先。
   其余克制处理：手绘边框只留给主按钮和立绘，别处用波浪细分割线 + 小号字距标签做
   层级（每个元素都套抖动边框只会变噪）；立绘不加框，脚下画一条地平线把角色钉住；
   时间设置用「＋/时/−」「＋/分/−」两列，大号手写数字左对齐、步进器靠右一行解决。
   头部右侧常显当前时间（不占额外高度）。立绘要脚踩地平线，别在框里居中悬空。
   待机页显示「下一次 05:42」和今晚还剩几次，而不是角色简介。
   真闹钟没法当场试，所以要有「体验一整夜」这个入口 —— 但**不要做成「跳过」按钮**，
   要让时间本身流得不均匀：离下一次闹钟越远走得越快，越近越慢，最后 2.5 秒回到实速
   然后响。速率曲线 rate=clamp((gap/2.5)^1.3, 1, 5400)，指数>1 让远处空白塌缩更快，
   落地仍由时间常数控制，所以减速必须看得见。目标是一整夜 20-70 秒走完。
   界面上别显示「×5400」这种没意义的数字，显示「1 秒 ≈ 1.5 小时」并随接近而收敛到
   「实速」。实现只用一个时间源：nowMs()=Date.now()+warp，每帧按当前速率往 warp 积分，
   这样钟面、调度、响铃页时间才自洽；真实 Date.now() 不要动（音量渐强仍走真实时间）。
   响铃期间流速强制回到 1 —— 处理闹钟的时候时间必须是真的。
   两个入口要分清：主按钮「设定闹钟」走真实时间（真闹钟不能跑在假时钟上），次级入口
   「体验一整夜」才进压缩模式，待机页明写「体验模式」。响铃页顶部放「今晚第
   N 次」和当前时间，用一条细线分开「发生了什么」和「要你做什么」，操作区落在拇指区。
   屏幕间加淡入上浮过渡。
   设置页必须一屏装下、不出现滚动条：做成弹性列，固定块占死，剩余空间全部交给立绘
   吸收（屏幕高角色画大、屏幕矮自动收）。尺寸分档用容器查询（container-type:size 挂在
   手机列上）而不是媒体查询 —— 桌面浏览器里这一列可能比窗口矮，媒体查询会判断错。
   只有极矮视口才退回可滚动，并全局隐藏滚动条：宁可让它滚，也不能把主按钮切掉。
   画布高度要贴着图形本身给，别留一大截空的（时间轴那种最容易踩）。
   注意：手写体是异步加载的，字体到位后文字块高度会变、弹性布局重排，画布的位图尺寸
   必须跟着重算（挂 ResizeObserver + document.fonts.ready），否则旧位图被非等比拉伸，
   角色看起来就是「被压扁」的。

3b. 选角色要做成游戏选人台，不要做成一堆卡片平铺：
   - 一次只显示一个角色的大立绘，左右箭头 + 左右滑动切换，底下一排圆点指示，
     切换时旧的滑出、新的带缓动滑入。
   - 切到谁就播一声谁的叫声（第一次点箭头顺手 init 音频）。
   - 每个角色要有自己的待机动作：小婴儿哭到一抽一抽、手脚乱蹬、嘴一张一合跟着
     哭声、掉眼泪；猫头轻点、耳朵抽动、会眨眼、尾巴甩；蚊子绕着飞且翅膀高频扇动；
     公鸡周期性引颈打鸣并画出声线；狗歪头、耳朵慢半拍地甩、伸舌头喘；电话一阵
     一阵地震、声波往外推。
   - 动效要靠拆笔画实现，不是整张图变形：写一个 part(shape, 笔画下标, 变换) ，
     给某几笔单独的旋转/位移/缩放和支点，这样才能只动耳朵、只伸头、只扇翅膀。
   - 响铃页复用同一套动效，换成朱红并让线条沸腾。

4. 画风：手绘。这是硬要求，不要用现成图标或字体图形。
   - 写一个 rough() ：所有线条都是「加抖动、描两遍、第二遍半透明」的笔触，
     圆头圆角。抖动用确定性噪声（sin hash），否则会每帧乱抖。
   - 数字 0-9 用手写笔画数据自己画（不要靠字体），六个角色画成手绘涂鸦，
     待机页画一只双铃闹钟（两个铃、锤把、两只脚、表壳、表盘、里面写时间）。
   - 一套手绘语言，两个色板：设置页和响铃页是纸（暖白纸纹 #f0e7d8 + 墨色 #2f2a24
     + 朱红 #c1503a）；待机的床头钟是夜（深墨底 #141117 + 暖白粉笔 #ded2be）。
     理由：凌晨三点亮一张白纸会晃眼。
   - 线条要「沸腾」：每 110ms 换一次抖动种子，像逐帧动画的呼吸线。选人台和响铃页
     沸腾，床头钟静止 —— 每个画面在画之前自己设定抖动种子，互不干扰。
   - DOM 元素的手绘边框用不对称圆角
     border-radius:255px 14px 225px 14px/14px 225px 14px 255px 配 2px 实线。
   - 中文用系统手写体（HanziPen SC / 手札体），拉丁走 Bradley Hand，回落 PingFang。
     不要加载网络字体。
   - 纸纹用内联 SVG feTurbulence 铺一层很淡的噪点，不要用图片。

5. 声音要真。真实录音和合成各用在对的地方：
   - 新生儿哭、猫叫、公鸡、狗吠用真实录音（Wikimedia Commons 上有 CC0 / CC BY-SA
     的素材）。剪成 1.5-6 秒，归一化，首尾各 30ms 淡入淡出，否则循环时会爆音。
     转成 AAC/m4a 单声道 56kbps —— 不要用 Ogg，Safari 解不了。写一个 CREDITS.md
     把作者、授权、改动逐条列清楚；CC BY-SA 的剪辑版本要声明以相同协议发布。
   - 蚊子和 On-call 告警继续用 WebAudio 合成，因为合成更对：蚊子本来就是纯音加
     翅频调制（窄带通锯齿波 + 随机声道漂移 + 忽远忽近），真实的 P1 告警本来就是
     方波三连。
   - 所有合成音都保留做兜底：录音加载失败要能自动退回合成，闹钟不能变哑。
   - 用 <audio> 元素而不是 decodeAudioData —— fetch 在 file:// 下会被拦，
     <audio> 不会。响铃时音量 26 秒内从 30% 渐强到 95%。

6. 网页闹钟的真实限制要在界面里直说，并且在工程上做到位：
   - 到点判断用 Date.now() 轮询，不要用一次性 setTimeout；后台被节流或切走再回来
     要能补触发，但只响一次，不要补一串。
   - 设定后申请 Wake Lock 保持屏幕常亮；拿不到就明确提示「锁屏后可能不会响」。
   - 响铃前 resume() 可能已被系统挂起的 AudioContext，否则闹钟是哑的。
   - 待机页不要每帧重画，每秒一次、且只在分钟或冒号变化时才真画（它要亮一整夜）。
```
