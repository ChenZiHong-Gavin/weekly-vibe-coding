# Paper Kite - 水墨放风筝

## 项目描述

做一个"感受风"的放风筝网页：在水墨留白的黄昏水景里，第一人称牵着一只风筝。用摄像头追踪手部，握拳抓住线、上下拉动收放线，牵引一只真实受力的风筝在风里起伏。还能自己设计风筝——选骨架、对称笔刷画皮、盖传统纹样图章，画完直接放飞。

## 技术要求

- 纯前端静态实现（HTML + CSS + 原生 JS + Canvas 2D），无需构建
- MediaPipe HandLandmarker（浏览器内、CDN 加载）追踪一只手 21 个关节点；画面全程本地不上传；无摄像头时自动回退，风筝自行乘风飞
- 交互只做"手拉线"：握拳 = 抓线，往下拉 = 收线并给风筝一股表观风让它窜升，往上送 = 放线；手只控制线，不直接拖动风筝
- 真·物理：风筝按空气动力学受力（升力恒垂直于相对风且朝上，失风能自恢复），线是不可伸长的硬约束（绷直 / 松弛画成悬链线）；第一人称、线轮固定、手的活动范围有限
- 风筝设计器：菱 / 沙燕 / 三角翼 / 六角 四种骨架（不同升力·重量·阻尼），对称笔刷蘸墨画皮，花 / 云 / 回纹 / 蝙蝠 / 鱼 / 古钱等传统纹样图章，烘焙成贴图放飞
- 水墨美学：宣纸底、夕阳与云霞、远山、水面波光与倒影、孤舟、芦苇、飞燕、随风花瓣；Web Audio 合成弦鸣 + 风声 + 水声 + 归鸟 + 虫鸣的黄昏声景
