# 记忆厨房

> 把照片当作食材，把合成当作做饭。用户上传几张照片放进食材库，拖上案板后给每一样选处理方式（切片保留细节、捣碎只取颜色和气氛、腌制让味道渗进整锅）和用量，再选烹饪方式（炖、炒、蒸、烤、生拌）和火候，按下「开火」。应用把这些食材和一份烹饪笔记（提示词）交给一个预留的图生图接口，做出一张从未发生过、却像是记得的新照片。出锅的菜可以保存、再来一锅，或放回食材库继续煮。没有接口时在浏览器里离线合成。视觉设计交给 Codex：手写菜谱本、深夜厨房、温热旧照片。
>
> 验收：示例食材一键入库；至少两样才能开火；本地合成在 30 秒内出锅且五种烹法结果可辨；菜可以放回食材库并直接上案板；刷新后食材库和餐桌都还在；手机单栏不横向滚动。
