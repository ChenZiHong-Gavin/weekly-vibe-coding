# Wire Score - 電線譜

## 项目描述

我脑袋里有一个画面：电线杆上的小鸟，可以看作钢琴谱；画面上方是夕阳和电线，下方本来想的是钢琴，后来换成更合画面的古琴：七弦横铺、十三徽、岳山，正调空弦就是宫商角徵羽；琴上两只写意的手，右手挑弦、左手在七徽按弦。做成一个应用。画风：新中式水墨绘本，致敬 80 年代上美影，强调大巧若拙的毛笔触感与宣纸纹理，低饱和矿物色，极简留白构图。先让 Codex 按同一构图出四张风格稿（淡墨留白 / 矿物色块 / 枯笔焦墨 / 水晕氤氲）再挑一张实现，选了枯笔焦墨；手要重新画，不要风格稿里那种糊成一团的。不要开始界面，不要任何说明文字和按钮，进去就是鸟飞过来。

## 技术要求

- 纯前端静态实现（HTML + CSS + 原生 JS + Canvas 2D），无需构建
- 五根电线从下到上就是 宫商角徵羽（C D E G A）；鸟停在线上即音符，横向位置即时间；一道风从左到右扫过，扫到的鸟跳一下、叫一声，底下的琴弹出那个音；一轮 64 格四小节，循环
- 鸟弹完自己飞走，下一句的鸟落在风身后的空线上；一轮即一句，按作曲规则生成：民歌节奏型、动机—接续—模进—收尾、单数句落徵双数句落宫、强弱拍、宫线低音鸟（低八度）、偶尔叠三度；不要随机游走
- 不说明的交互：点电线落鸟、点鸟惊飞、按琴键喚鸟；键盘 [ ] 调快慢、空格停续
- 鸟要小、写意，三笔：浓墨一点是头、淡墨一扫是身、细笔一撇是尾，每只胖瘦尾势不同；会飞进来落线、飞走、偶尔转头甩尾
- 画面：夕阳、云霞、远山、飞燕、随风花瓣；电线一打开从左到右牵出来；右下只留竖排题字「電線譜」
- 笔触全部程序生成、不贴图：枯笔=多条不等宽笔毫沿同一路径各有缺墨段，提按=沿路径变宽的带状多边形，纸纹=固定种子的细粒加纤维；静态层缓存，动态元素用固定种子不闪
- Web Audio 合成：古琴用 Karplus-Strong 拨弦（丝弦音色，宫线胖鸟弹空弦低音）、鸟鸣（短滑音）、黄昏风声；不用音频文件
