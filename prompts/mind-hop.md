# MIND HOP - 附身潜入

## 项目描述

做一个第三人称潜入游戏，能力原型来自琴·葛蕾的"跳"：不是远程操控，而是把意识跳进 13 米内某个人的脑子里。核心不是让你变强，而是让你**变成别人**。

关键约束（这是整个游戏的地基）：

- **有两个视角**：琴自己的，和被她操控的人的。控制目标连同相机整体切换。
- **意识出去时，本体留在原地**，一动不动、毫无防备、还发着微光。右下角一个画中画永远盯着它，而且**那具身体可以用方向键操舵**（梦游一样慢），不是只能干看着的仪表盘。
- **附身和脱离时，被附身的人都会踉跄一下** —— 而且旁人看得见，这是要付代价的。
- **不要念动力。** 不能推东西、不能飞、不能打。
- 玩法必须由附身驱动：读记忆找情报、制造骚乱调虎离山、附身守卫从正门走进去。

## 技术要求

- Three.js + Vite，纯静态前端，无后端、无外部网络请求（部署在 GitHub Pages 子路径下）
- 程序化生成城市（着色器画楼房窗户，零贴图素材）
- 340 个带骨骼动画的单位跑真实人群力学（Helbing social force），用 VAT（顶点动画纹理）渲染：动画烘焙成纹理 + InstancedMesh，而不是 340 个 SkinnedMesh
- 跨骨架动画重定向，且要兼容 T-pose 与 A-pose 两种绑定姿态（按世界肢体指向对齐，不能保留"相对绑定姿态的形变量"）
- 两套并行操作：`WASD` 永远控制"你此刻穿着的身体"，`方向键` 永远控制"你自己的身体"，严格不串
- 守卫是"眼睛"不是靶子：怀疑度驱动（看到异常 → 走过来盘查 → 贴近制服），听到骚乱会离岗
- 两条资源：**链条稳定度**（离本体越远衰减越快，逼你定期回去把身体挪近）和**暴露度**（满了就输）
- 音频全程序合成（24 个波形，无音频文件），**双耳设计**：意识在外时本体那侧的声音走另一条通路并低通到 2.6kHz 以下 —— 听得见但闷；靴子声传得比皮鞋远，能靠耳朵分辨远处是守卫还是平民
- 首屏加载要小：模型剥掉游戏用不到的数据后分批加载，先能玩再补外观
