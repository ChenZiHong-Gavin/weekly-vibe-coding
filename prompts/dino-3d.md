# Prompt for 3D Dino Run

```
写一个 3D 恐龙跑酷网页游戏，单文件 HTML（Three.js 通过 CDN importmap 加载，无构建步骤、无后端）。核心概念：

1. 3D 无尽跑酷：5 条车道（Z 轴 -2 到 2），速度随时间递增；操作 Space/↑ 跳跃（长按跳更高）、↓ 下蹲、A/D 左右侧移。
2. 沙漠场景：纪念碑谷（Monument Valley）风格的台地（mesa）、暖色天空、稀疏岩石与昼夜交替（按真实时间切换）。
3. 障碍：小/高仙人掌、岩石、需下蹲通过的横梁（beam）、高低空飞行的翼龙（ptera），后两者可下蹲躲避；宽体变体会横跨整条跑道。
4. 收集与连击：金币、宝石；连续越过障碍触发连击倍率（显示 x1~x5），擦身而过（near miss）加分。
5. 四种道具：护盾（吸收一次碰撞）、磁铁（吸金币）、二段跳、冲刺（加速），各带计时与专属视觉特效。
6. 翼龙用 GLB 模型（GLTFLoader 加载、克隆复用；加载失败回退到程序化模型），翅膀翻飞动画。
7. 音效：WebAudio 合成跳跃 / 金币 / 连击 / 碰撞等音效。
8. 可调参数面板：实时调节雾、相机、地面偏移、像素比、阴影等。
9. 性能：粒子系统、地面装饰与台地用视差滚动，桌面端目标 60fps。

视觉风格：暖色沙漠氛围，ACES 色调映射，PC 与移动端都能跑。所有代码、样式、UI 都内联在一个 index.html 里（翼龙模型单独放在 models/）。
```
