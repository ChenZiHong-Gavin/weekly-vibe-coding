# Prompt for Sky Pilot

```
写一个浏览器飞行模拟器网页，单文件 HTML（Three.js 通过 CDN importmap 加载，无构建步骤、无后端）。核心概念：

1. 一颗程序化生成的微型星球 —— 玩家驾驶小飞机围绕它飞行，而不是在平面上飞。
2. 程序化地形：3D 梯度噪声 + FBM + 山脊（ridged）噪声把球面顶点沿法线位移，做出大陆/山脉/海岸线；地表按海拔和坡度用顶点色过渡（沙滩→草地→岩石→雪顶），低于海平面处加一层半透明海水球壳。
3. 六座可切换的风格星球：霓虹赛博、地中海艳阳、雪山小镇、沙漠绿洲、热带海滨、现代都市。每座有独立的地形振幅/海平面/配色、天空渐变、环境光和建筑色彩。
4. 程序化城市：用斐波那契螺旋在球面上撒点，放 3–5 个"市中心"种子，按角距离算城市化系数 u，核心区楼高且密、郊区矮且疏；建筑有多种原型（矮楼/板楼/退台塔楼/圆塔/尖塔），高度随机形成天际线；弯曲道路网格、城市公园、以及每座市中心一个地标（电视塔/钟楼/宣礼塔/霓虹尖塔）。植被用 InstancedMesh 散布到野外。
5. 街机飞行物理：重力和升力沿径向（垂直地面），让飞机在任意高度都能沿圆周飞行（巡航速度时净向心力 = V²/当前半径）；A/D 横滚让速度绕径向轴旋转=转弯，W/S 俯仰让速度绕切线右轴旋转=爬升/俯冲；有阻力、推力、速度上下限和地形碰撞。
6. 计时赛玩法：每个市中心地标上方放一个发光检查点环（Torus + 光柱），按顺序穿越完成环球一圈。当前目标绿色脉冲、已通过变金色；屏外时屏幕边缘出现指向箭头和距离；HUD 显示计时、目标进度、速度/高度/油门；最佳成绩存 localStorage。
7. 判定与反馈：飞到环的圆柱触发区内即通过（不要要求精确穿过薄环平面），通过时粒子爆发 + 屏幕闪光 + 环放大 + WebAudio 合成音效；硬撞地会传送回当前检查点并加 2 秒罚时。
8. 操作：W/S 俯仰、A/D 横滚、Shift/Ctrl 油门、Space 刹车、Enter 开始/重开、R 重置。有开始遮罩和结算面板。
9. 性能：所有建筑几何按材质桶 mergeGeometries 合批（body/glass/window/neon/roof/road 等），植被用单个 InstancedMesh，环和光柱是少量独立 mesh；桌面端目标 60fps。

视觉风格：明亮但有氛围，渐变天空着色器天穹 + 星空（白天星空自动淡出），ACES 色调映射，软阴影，PC 端和移动端都能跑。所有代码、样式、UI 都内联在一个 index.html 里。
```
