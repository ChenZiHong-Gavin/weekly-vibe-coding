# Prompt for Camera Twin

```
做一个佳能 EOS R6 Mark III 的三维数字孪生网页（Vite + Three.js + 本地 Node 服务）。核心概念：

1. 三栏界面：左侧部件列表（可搜索），中间三维舞台，右侧"问问这台相机"对话。
2. 部件知识库：按佳能官方手册"部件名称"页整理 55 个部件，每个有 id、中英文名、所在面、说明、用法。
3. 三维模型：程序化 Three.js 机身，每个部件是带 userData.part 的独立对象；1 单位 = 1 厘米，+Z 朝摄影师。写一个契约文件规定部件 id、尺寸、坐标和可选控制件（模式转盘、翻屏、卡槽盖），附无头校验脚本；模型未实现时用方块占位模型跑通全部功能。
4. 交互：点击部件高亮并弹出说明卡；正/背/顶/左/右/全景视角按钮；聚焦时镜头从机身外侧飞向部件。
5. 讲解员：服务端用 Anthropic SDK 调 Claude，唯一工具 present_camera 提交中文回答加最多六步演示（部件、聚焦、隔离显示、视角、控制件）。前后端共用一份校验，只允许清单里的部件和操作。密钥只在本地 .env。
6. 演示执行：分步高亮、飞镜头、翻屏/转盘动画，可点击某步重看，可停止和恢复。
7. 建模参考：下载官方部件线稿和官方正投影照片放到 public/reference-images，写一份建模简报交给 Codex 编写 src/model/r6iii.js。

视觉风格：暖白棚拍，ACES 色调映射，软阴影。
```
