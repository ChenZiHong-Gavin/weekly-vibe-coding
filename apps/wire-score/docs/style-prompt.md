# 給 Codex：為「電線譜」出 4 張風格稿

## 背景

`apps/wire-score` 是一個純前端 Canvas 應用：夕陽下兩根電線杆、五根電線當五線譜，停在線上的鳥是音符；畫面下方一張古琴，兩隻手在上面彈。現在的畫面見 `apps/wire-score/docs/screenshots/wire-score.png`，構圖和元素**全部保留**，只換畫風。

目標畫風：**新中式水墨繪本，致敬 1980 年代上海美術電影製片廠**（《山水情》《牧笛》《鹿鈴》那一路）。要點：

- **大巧若拙的毛筆觸感**：線條有枯有潤、有頓挫，不要光滑的矢量線；形要拙、要概括，不要寫實。
- **宣紙紋理**：紙是有肌理的，墨落在紙上有洇、有飛白。
- **低飽和礦物色**：赭石、石青、石綠、朱砂、藤黃、花青，全部壓灰壓淡，一張圖最多三種色，墨為主。
- **極簡留白構圖**：大面積空白是畫的一部分，元素少而準。

## 請你做什麼

用你的圖片生成能力出 **4 張** 風格稿，1400×900，PNG，存到 `apps/wire-score/docs/style/A.png … D.png`。四張構圖一致（和現有截圖一樣：天空占上三分之二，電線在中段，古琴在底部，右下角豎排題字「電線譜」），但各走一個方向：

- **A · 淡墨留白**：九成是淡墨和宣紙本色，只有夕陽一點赭石。最接近《山水情》。
- **B · 礦物色塊**：遠山石青、琴面赭石、夕陽朱砂，色塊邊緣是毛筆掃出來的，不是填色。最像繪本。
- **C · 枯筆焦墨**：電線杆、鳥、琴都是枯筆焦墨，飛白多；天空是一層很淡的藤黃暈染。最硬朗。
- **D · 水暈氤氳**：濕墨為主，遠山和雲是暈開的，鳥和線是畫面裡唯一清楚的東西。最柔。

每張圖都要畫出：夕陽、幾縷雲、遠山、兩根電線杆（帶橫擔）、五根微微下垂的電線、線上十幾隻鳥（寫意三筆：濃墨點頭、淡墨掃身、一撇尾）、一張俯視的古琴（七弦、十三徽、岳山）、琴上兩隻寫意的手、右下角豎排「電線譜」三字。

## 同時給我的

每張圖旁邊附一段 **可實現筆記**（寫進 `apps/wire-score/docs/style/NOTES.md`）：

1. 調色板：每種顏色的十六進制和用在哪裡（紙色、墨色三階、兩三種礦物色）。
2. 筆觸怎麼做：線條的粗細變化、枯潤比例、哪些邊是硬的哪些是暈的。
3. 紙紋：顆粒大小、對比度，是鋪滿還是只在留白處。
4. 這張圖裡哪些是靠畫法出來的、哪些是靠構圖出來的——我要在 Canvas 2D 裡用程序畫出來，不能貼圖。
