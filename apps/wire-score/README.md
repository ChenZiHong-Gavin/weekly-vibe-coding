# 電線譜

一个把**电线当五线谱**的小应用：画面上方是夕阳、两根电线杆、五根电线；停在线上的小鸟就是音符；画面下方是一张古琴。画风是**新中式水墨绘本，致敬 80 年代上美影**：熟宣暖米的纸、枯笔焦墨的线、极淡的藤黄天空和一点灰赭夕阳，大面积留白。没有按钮，没有说明，打开就是鸟飞回来。

## 它怎么成立

- 五根电线从下到上是 **宫 商 角 徵 羽**（C D E G A）。只有五根线，所以只能是五声音阶——鸟怎么落都好听。
- 鸟在线上的**横向位置就是时间**。一道风从左到右扫过电线，扫到谁，谁就跳一下、叫一声，底下的琴就弹出那个音；一轮是四小节、64 格（一格一个十六分音），默认 7 秒；同一格落几只鸟就是和弦。
- 下面是一张古琴，正调七弦 徵羽宫商角徵羽；电线上的宫商角徵羽对应三到七弦。鸟是按音，比空弦高一个八度；宫线上的胖鸟弹空弦当低音。风扫到谁，那根弦就颤一下。琴上有两只水墨的手：右手在岳山旁挑弦，左手在七徽上按弦（按音都在七徽，所以左手只在弦之间上下走），弹空弦低音时左手抬起。
- **一轮就是一句，风扫过的鸟飞走，下一句的鸟落在风身后的空线上。** 所以每一轮都是新的一句，又连成一首歌。
- **句子是按作曲规则生成的，不是乱落**：
  - 节奏从十种民歌常见的一小节节奏型里抽两种，排成「甲 乙 甲 收」四小节，收尾那小节只留长音。
  - 旋律是「动机 — 接续 — 模进 — 收尾」：第一小节随机走出一个动机（级进为主），第二小节接着走，第三小节把动机整体上移或下移一度再唱一遍，第四小节往终止音走。
  - 单数句落徵（半终止，像没说完），双数句落宫（全终止，说完了）。同一副节奏骨架用四句，一首歌唱完再换。
  - 强拍重、弱拍轻；第一、三小节的强拍在宫线上落一只胖鸟当低音，弹的是低八度；偶尔在第二、四小节强拍叠一个三度。
  - 琴音是拨弦合成（Karplus-Strong），再加一层合成的混响。

## 怎么玩

打开就行。想插手也可以，都不说明，自己发现：

- **点电线**：落一只鸟。
- **点鸟**：惊飞。
- **拨弦**：点琴上的弦出声；拨到标着宫商角徵羽的弦，会有一只鸟飞来落在对应的线上、风当前的位置。
- 键盘 `[` `]` 调一轮的快慢（5–20 秒），空格 停 / 续。

## 运行

纯静态，无需构建，直接双击 `index.html` 即可，或：

```bash
cd apps/wire-score
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> 浏览器要有一次点击才肯出声，点画面任何地方都行。`?demo` 参数会跳过开场动画、直接带一群鸟入画，方便截图。

## 设计取向

- **一件事当另一件事**：电线本来就有五根，鸟本来就会落上去、飞走、再落回来。应用只做了一件事：让它响。
- **生成但不随机**：第一版是随机游走，不出错音但像风铃；现在用节奏型、动机重复、模进和终止式约束，每首还是不同的，但每首都像一首歌。
- **画风走「枯笔焦墨」**：先让 Codex 按同一构图出四张风格稿（`docs/style/A–D.png`，笔记在 `docs/style/NOTES.md`），选了 C。所有笔触都是程序画的，不贴图：枯笔是多条不等宽的笔毫沿同一条路径走，各自有缺墨段，缺墨处直接露纸；提按是沿路径变宽的带状多边形；纸纹是固定种子的细粒加纤维；所有随机都用固定种子，动画里不闪。纸、天、云、山、日、杆、琴身在窗口变化时画一次存成底层，每帧只画风、线、鸟、弦、手。
- **鸟是三笔**：焦墨一点是头，烟灰一扫是身，枯笔一撇是尾；每只胖瘦、尾势都不同。
- **手是一笔轮廓**：俯视的手形用一笔有提按的焦墨勾出来，掌心一层淡墨，袖子一抹淡墨往画外去。
- **为什么是古琴**：七根弦横着铺在琴面上，和上面五根横着的电线是同一种线条；正调空弦本来就是宫商角徵羽；丝弦那种暗、长、带一点杂音的声音也比钢琴更像黄昏。
- **声音全部合成**：琴音是 Karplus-Strong 拨弦（激励先抹软、尾巴再压高频，像丝弦不像钢弦）+ 一点指甲触弦的噪声，鸟鸣是一段短促的频率滑音，底下铺一层慢慢起伏的滤波噪声当黄昏的风。没有任何音频文件。
- **不做开场、不做按钮、不做节拍器、不做导出**。看，听。
