# 烹饪舞台：材质与光照

原舞台的主要问题是缺少材质之间的联系：锅沿、汤面、照片与火都各画各的，阴影没有统一方向，食材像贴在圆盘上。此次保留“烹饪照片”的比喻，重点让承载它的厨房具有可信的深度、反射和重量。

## 光照模型

左上约 10 点钟方向为暖色大面积主光；右侧提供低强度冷色环境反射；燃气从锅底提供跳动的暖光。所有接触阴影落向右下。锅沿采用方位相关金属反射、细划痕与双层卷边，锅壁下凹；液体沿锅壁变暗，并保留掠射反光与泡沫。食材用缓存的漫反射材质、随朝向变化的切面高光、厚度和湿润表面表现体积。画面最后叠加轻微暗角与固定细颗粒。

## 各阶段

- **备料**：预渲染木纤维、板缝、刀痕；照片有厚度和定向投影。切片有明亮切面与暗边；碎泥是圆润带湿光的颗粒；腌料保持深色酱汁和光膜。刀刃增加窄幅镜面反射，木柄增加明暗与铆钉，小碗呈釉面。`drawTool` 的接口和时序保持不变。
- **下锅**：按预处理生成长条、软团或圆钝湿块；空中翻滚、透视压缩、加速落下。接触时出现短暂水冠、双边波纹与带高光的水滴，热油产生细小飞溅，撞击带衰减镜头震动。
- **烹饪**：多层湍动云纹形成蒸汽体积，低处接受暖光，升高扩散消失；气泡先鼓起、反光，再破成细泡。成品从食材下方通过逐渐扩张的清澈区域显露，叠加分带折射；食材软化、缩小、浸没，最后退出。
- **出锅**：熄火、锅具过渡为釉面瓷盘，背景转至木桌与亚麻布，蒸汽消散，保持原有成品与标题。

## 各方法

| 方法 | 视觉与运动 |
| --- | --- |
| 炖 | 琥珀汤面、锅壁遮蔽、油膜、碎窗高光、泡沫圈；下半截浸色与折射；中心较密的沸泡、缓慢对流、厚蒸汽。 |
| 炒 | 深色带微纹理的锅底，薄油反光、短促油烟；颠锅、腾空、翻转、落回时油点飞溅。 |
| 蒸 | 金属打孔蒸屉、带反射和冷凝水珠的玻璃盖；少量位移、浓白蒸汽；出锅揭盖。 |
| 烤 | 暗色铸铁烤槽、受光的槽边；食材逐渐焦化并带烤纹，瘦长灰烟与少量余烬。 |
| 拌 | 始终使用木桌、亚麻布和瓷盘；轻拌与清亮酱汁反光，无炉火、烟或热油飞溅。 |

## 性能与边界

仅 Canvas 2D，无外部素材或运行时依赖。木板、炉面、锅体、瓷盘、玻璃盖、泡沫、云纹、十帧火焰图集，以及裁剪后的食材材质均按会话缓存。复杂图层在 1200×900 逻辑画布绘制，再一次呈现到最高 DPR 2 的显示画布；没有逐帧像素读取。预处理画面复用固定尺寸画布，避免捣碎震动时按浮点尺寸无限建缓存；粒子有数量上限，运动与寿命按秒计算。减少动态模式仅按进度推进，不运行物理、粒子、抖动或工具运动。

`PHASES`、文案、`createStage().run()` 和原有 compositor 的 plan/render 算法保留。照片内容仍然是照片；液体折射、烟体积和光照是有方向性的绘画近似，不是流体或光线追踪模拟。

## 验证

五种方法各留一张八帧分镜于 `docs/screenshots/stage-*.jpg`，逐张查看备料、落锅、烹饪与出锅；另外检查混合三种预处理、DPR 2、减少动态与取消路径。普通 Chromium 的 Apple M5 / Metal 实测，DPR 2 稳态烹饪帧间隔中位数 8.3 ms、95 分位约 9.0 ms（三种备料混合，120 Hz 显示环境）。无头截图浏览器使用 SwiftShader 软件光栅，不能代表硬件帧率。

验证命令：`npm test`（23 项）、`npm run build`、`node tests/browser.mjs`（五种成品最小差异 39/255，控制台无错误）。`node tests/stage-paths.mjs` 验证减少动态与取消；`STAGE_HEADED=1 node tests/stage-performance.mjs stew --mixed` 重现硬件基准。额外的 `stage-mixed-prep.jpg` 检查三种备料形态同锅出现。
