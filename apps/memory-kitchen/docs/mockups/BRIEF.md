# 记忆厨房 · 单区布局示意图简报（给 Codex）

## 背景

现在的页面分成食材库 / 案板+灶台 / 餐桌三栏（见 `../screenshots/02-dish.png`），用户觉得分区太多，要改成**只有一个烹饪区**：整页就是一张灶台 / 一口锅 / 一块案板，所有操作都发生在同一个画面里。

在正式改代码前，先出 **4 版不同思路的静态示意图**给用户挑。

## 产品逻辑（不变）

1. 照片是食材：用户拖入或点选照片（可多张，最多 5 张同时下锅）。
2. 每样食材可以选处理方式（切片 / 捣碎 / 腌制）和用量（少许 / 适量 / 大量），可以改名、写一个词当"味道"。
3. 选烹饪方式（炖 / 炒 / 蒸 / 烤 / 生拌）和火候（文火 / 中火 / 大火），可以给菜起名，按「开火」。
4. 开火后照片在锅里经历备料 → 下锅 → 烹饪 → 出锅，变成一张全新的照片（一段新记忆）。
5. 出锅的菜可以保存、再来一锅，**也可以放回当食材继续煮**（这是核心 vibe，记忆可以递归烹饪）。做过的菜要能回看。
6. 右上角有「灶台设置」（生图接口）。

## 要出的四版（每版一个独立 HTML 文件，`docs/mockups/v1.html` … `v4.html`）

每版都是**一个画面、一个烹饪区**，但组织方式不同，例如（可以自己发挥，但四版要明显不同）：

- **v1 一口大锅居中**：锅占画面中心，食材照片像配料一样围在锅边（拖进锅里就是下锅），烹法和火候是锅下面的旋钮，做好的菜从锅里端出来摆在画面底部一排小盘子里。
- **v2 灶台俯视**：俯视一整张灶台/案板，左手边是摊开的照片（食材），中间是锅，右手边是一只盘子（出锅后落在这里），没有面板和卡片，所有控件都画成厨房里的实物（刀=切片、杵=捣碎、碗=腌制，火苗数=火候）。
- **v3 一条流水线**：从左到右一条线：照片 → 刀工 → 锅 → 盘子，但它们在同一个场景里而不是四个面板，当前步骤放大、其他步骤缩小。
- **v4 极简一张图**：画面就是正在煮的那锅/那张图，占满；食材缩略图贴在画面一角，烹法火候是底部一行小字按钮，历史的菜是侧边一列小圆盘。

## 视觉要求

- 延续现有设计语气（见 `../../src/style.css` 和 `../DESIGN_NOTES.md`）：手写菜谱本、深夜厨房、米纸白 + 鼠尾草绿 + 旧木 + 砖红；标题宋体、批注楷体。但示意图可以比现在更大胆。
- 用 `assets/` 里的三张真实照片当食材，`assets/dish.jpg` 当一道做好的菜。
- 每版都要画出"正在煮"或"刚出锅"的状态，让人看得出锅里有东西。
- 桌面尺寸 1440×1000 为准；不要求响应式；纯静态 HTML+CSS（可以内联 SVG），不要 JS 交互，不要外部依赖（Google Fonts 可以）。
- 每版文件顶部加一行小字注明版本名和一句话思路。
