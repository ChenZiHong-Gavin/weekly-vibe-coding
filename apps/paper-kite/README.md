# 紙鳶 · 御風

一个在浏览器里"感受风"的放风筝原型，取**水墨留白**的样子：宣纸底、极细墨线、大量负空间，只点一抹朱红。没有输赢，只有线那头传来的一股活的力量。

## 内核：真·物理仿真

风筝不再被公式"摆"在天上，而是**真的在受力飞**。每一帧都在解算四个力：

- **升力 + 阻力**（平板翼模型，∝ 相对风速² × 迎角，作用在风筝面上）
- **重力**
- **系绳张力**（真绳子：绷直才拉、松了垂成悬链线，只能拉不能推）

所有行为都是**从物理里自己长出来的**，没有一句写死：

- 阵风来 → 相对风速骤增 → 升力尖峰 → 风筝上窜、过冲、再被线拽回 → **自然的摇摆**
- 风变弱 → 升力不足 → **失速下沉**，线松垂
- 收线 / 放线 → 真的改变线长与张力 → 风筝窜高 / 沉降、荡向不同位置
- 风向变了 → 迎角与姿态跟着变
- 起飞、爬升、下坠、线的绷紧松垂，全是仿真结果

不做断线重来、不计分——realism 本身就是乐趣（贴合"感受那股活的力量"）。手边的墨条只是**张力读数**，让你"看见"线上的拉力。

## 怎么玩

1. 用浏览器打开 `index.html`。
2. **按住空格** 迎风奔跑，把风筝送上天（风够大时它自己也会起）。
3. **按住画面**当绕线器摇把：指针停在按下点 **下方 = 持续收线**，**上方 = 放线**，松手 = 线不动（↓ / ↑ 键同样）。
4. 感受线上的拉力——阵风顶上来时那股窜劲，失风时的沉坠。
5. 右上角墨字 **聲 / 真風** 开关声音与真实天气。**一定要开声音**：弦鸣随张力与风速变化。

## 用真手牵线（摄像头手部追踪）

点右上角 **「用手牽線」**，授权摄像头后，屏幕里会画出一只**水墨的手**镜像你：

- **手往下拉 = 收线**（张力上升，风筝被带得往上窜）
- **手抬起 = 放线**
- **猛地一顿 = 顿线**（张力尖峰）

手控制的是**那根线**，不是风筝——风筝始终自己在风里飞，只通过线的张力感受你的拉扯。摄像头画面**全程本地处理**（MediaPipe，浏览器内运行），不上传。没摄像头 / 不授权时自动回退到鼠标 + 键盘。

## 运行

摄像头要求安全环境，**必须用本地服务打开**（`file://` 拿不到摄像头）：

```bash
cd wind-kite
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> - 手部追踪首次需要联网下载模型（MediaPipe，约几 MB）；之后可打包到本地离线用。
> - 只玩鼠标/键盘版可直接双击 `index.html`（但摄像头牵线用不了）。
> - "真实天气"需要定位授权、请求 open-meteo 公共接口；离线或拒绝时回退到模拟风。

## 设计取向（为什么这么做）

- **风的存在感靠三条替代通道**：手感（线的形状）、声音（弦鸣）、环境（被吹动的东西）。浏览器里没有触感，只能这样补。
- **风要"活"**，不是随机噪声：基础风 + 阵风 + 高度分层，往上爬变成有层次的探索。
- **不做等级、金币、每日任务、排行榜**。安静地放，就够了。
