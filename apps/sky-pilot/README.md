# Sky Pilot · 星球飞行计时赛

一个单文件 HTML 的浏览器飞行模拟器。驾驶小飞机环绕一颗程序化生成的微型星球飞行，穿越城市上空的发光环完成计时赛。全部使用 Three.js，无构建步骤、无后端依赖。

## 功能亮点

- **程序化星球地形**：3D 梯度噪声 + FBM + 山脊噪声在球面上生成大陆、山脉、海岸线，地表按海拔/坡度做顶点色过渡（沙滩 → 草地 → 岩石 → 雪顶），并叠加半透明海水。
- **六座风格各异的城市星球**：霓虹赛博星、地中海艳阳星、雪山小镇星、沙漠绿洲星、热带海滨星、现代都市星。每颗星球有不同的地形、配色、建筑原型与地标。
- **多样化城市生成**：斐波那契分布的市中心、按城市化系数变化的建筑高度与密度、退台塔楼 / 圆塔 / 板楼 / 尖塔等多种建筑原型、弯曲道路网格、城市公园与实例化植被。
- **街机飞行物理**：径向重力 + 速度升力 + 阻力/推力，重力随高度自适应，飞机在任意高度都能沿圆周飞行；横滚转弯、俯仰爬升。
- **计时赛玩法**：每座城市地标上方有一个发光检查点环，按顺序穿越完成环球一圈，屏外导航箭头指路，碰撞坠毁会传送并加时，最佳成绩保存在 localStorage。
- **全部离线**：Three.js 通过 CDN importmap 加载，除此之外只有一个 `index.html`。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W` / `S` | 俯仰（爬升 / 俯冲） |
| `A` / `D` | 横滚转弯 |
| `Shift` / `Ctrl` | 油门加 / 减 |
| `Space` | 刹车 |
| `Enter` | 开始 / 重开计时赛 |
| `R` | 重置飞机到当前检查点 |

## 快速开始

这是一个纯静态单文件应用，不需要安装依赖。

### 方式一：直接打开
用浏览器直接打开 `index.html` 即可（部分浏览器对本地 `file://` 的模块加载有限制，如遇白屏请用方式二）。

### 方式二：本地静态服务器
```bash
# 在 apps/sky-pilot 目录下
python3 -m http.server 8765
# 然后访问 http://localhost:8765/index.html
```

或使用任意静态服务器（`npx serve`、`npx http-server` 等）。

## 技术栈

- [Three.js](https://threejs.org/) r160（CDN importmap）
- 原生 ES Modules，无打包工具
- 程序化几何：`mergeGeometries` 按材质桶合批、`InstancedMesh` 散布植被
- 渐变天空着色器、WebAudio 合成音效
