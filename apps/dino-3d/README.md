# 3D Dino Run · 恐龙跑酷

一个单文件 HTML 的 3D 无尽跑酷游戏。在纪念碑谷（Monument Valley）风格的沙漠中奔跑，跳过仙人掌、蹲下穿过横梁、躲避飞来的翼龙，收集金币与宝石，用护盾、磁铁、二段跳、冲刺等道具冲击更高连击。全部使用 Three.js，无构建步骤、无后端依赖。

## 功能亮点

- **3D 无尽跑酷**：5 条车道，速度随时间递增；跳跃（长按跳更高）、下蹲、左右侧移躲避障碍。
- **沙漠场景**：纪念碑谷风格的台地（mesa）、暖色天空、稀疏岩石装饰与昼夜交替。
- **多种障碍**：小/高仙人掌、岩石、需下蹲通过的横梁（beam）、以及高低空飞行的翼龙；宽体变体会横跨整条跑道。
- **收集与连击**：金币、宝石；连续越过障碍触发连击倍率（显示 x1~x5），擦身而过（near miss）也有加分。
- **四种道具**：护盾（吸收一次碰撞）、磁铁（吸金币）、二段跳、冲刺（加速），各带计时与专属视觉特效。
- **翼龙 GLB 模型**：`models/pterosaur.glb`（烘焙贴图，已压缩至约 300KB），加载后克隆复用；加载失败自动回退到程序化翼龙模型。
- **可调参数面板**：右上角 ⚙ 实时调节雾、相机、地面偏移、像素比、阴影等，改动即时生效。
- **全部离线**：Three.js 通过 CDN importmap 加载，除 `models/pterosaur.glb` 外只有 `index.html`。

## 操作

| 按键 | 功能 |
| --- | --- |
| `Space` / `↑` / `W` | 跳跃（长按跳更高） |
| `↓` / `S` | 下蹲 |
| `A` / `D` / `←` / `→` | 左右切换车道 |
| `P` | 暂停 |
| 点击 / 触摸 | 跳跃（移动端） |

## 快速开始

这是一个纯静态单文件应用，不需要安装依赖。

```bash
# 在 apps/dino-3d 目录下
python3 -m http.server 8765
# 然后访问 http://localhost:8765/index.html
```

或使用任意静态服务器（`npx serve`、`npx http-server` 等）。

> 注意：翼龙模型通过 `fetch` 加载，直接双击 `file://` 打开会被浏览器 CORS 拦截（此时会自动回退到程序化翼龙，游戏不受影响）。推荐用本地静态服务器运行。

## 技术栈

- [Three.js](https://threejs.org/) r160（CDN importmap）
- GLTFLoader 加载翼龙 GLB 模型
- WebAudio 合成音效
- 原生 ES Modules，无打包工具

## 目录结构

```
apps/dino-3d/

└── models/
    └── pterosaur.glb       # 翼龙模型（烘焙贴图，已压缩）
```
