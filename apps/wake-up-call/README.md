# Wake Up Call · 叫醒服务

**明早，谁来叫醒你？** 六位有脾气的叫醒专员，六种不太讲道理的早晨。

一个极简手绘闹钟，也是适合录屏展示的小作品。没有账号、安装步骤和后端；角色、时间和声音偏好会记在当前浏览器中。

## 打开

[在线体验](https://chenzihong-gavin.github.io/weekly-vibe-coding/wake-up-call/) · [创作 Prompt](../../prompts/wake-up-call.md)

直接打开 `index.html`，保留旁边的 `theme.css` 和 `assets/`。也可以启动本地服务：

```sh
cd apps/wake-up-call
python3 -m http.server 4173 --bind 127.0.0.1
```

访问 <http://127.0.0.1:4173>。

## 三个入口

- **就让它叫醒我**：真实时间的闹钟，采用页面上预览的同一份响铃计划。
- **体验一整夜**：加速等待，临近响铃时减速，最后 1.2 秒恢复实速。处理角色任务时始终走真实时间。
- **先试着叫醒我**：立即试玩当前角色的完整叫醒流程；完成后回到选人，也可以随时返回。

闹钟需要保持页面在前台、屏幕不锁定。支持时会自动申请屏幕常亮；申请失败或被系统释放时会显示提示。网页不能保证后台或锁屏时响铃。

## 六位叫醒专员

| 角色 | 响铃安排 | 怎么让它停下 |
| --- | --- | --- |
| 新生儿 | 每 2–3 小时一次，直到起床 | 长按喂奶，再慢慢向下拖动放回床上 |
| 家猫 | 提前约一小时开始，反复回来 | 在标记进入红色区域时点击，开 4 个罐头 |
| 蚊子 | 夜间随机几次，加上起床时间 | 找到它、拍它；没拍到也会暂时飞走 |
| 公鸡 | 提前 40 分钟一次，准点一次 | 没有关闭按钮，等它叫完 |
| 大型犬 | 准点一次 | 按住，陪它遛约 5 秒 |
| On-call 值班 | 夜间随机 1–3 次，加上起床时间 | 踩准节奏，处理 4 条告警 |

节奏点击失误不会扣掉已有进度。喂奶后哭声暂停；放得太快会惊醒。拖动必须从滑块开始，不能点底部跳过过程。

## 画面和操作

暖纸色、朱红、逐笔绘制的角色和手写时钟。每个角色有自己的动作、台词和早晨收据。入夜后切换为深绿色床头钟，显示下一次响铃时间和整夜进度。

桌面使用双栏构图；手机是单列选人台，常用竖屏尺寸一屏容纳操作，特别矮的窗口允许滚动。字体使用本机字体，没有网络字体或第三方前端依赖。

- 左右箭头、滑动角色或直接点击六个小头像切换角色。
- 点击时间直接修改；时、分按钮支持长按连续调整。
- 键盘左右键可切换角色；按钮支持 Tab、Enter。长按任务支持空格，放下宝宝支持按住下方向键。
- 声音开关会影响试听和响铃，设置会保存；系统“减少动态效果”偏好也会生效。

## 录屏建议

横屏用 1440 × 1000 左右的窗口，竖屏用 390 × 844。先设置好录音音量。

1. 停在家猫：展示「你的闹钟？我才是。」
2. 切到 On-call，让告警和「你睡了，服务也睡了。」形成第二个笑点。
3. 点击「先试着叫醒我」，展示 4 次操作和即时反馈。
4. 返回选大型犬，点击「体验一整夜」：纸张入夜、时钟快进、响铃、遛狗，再到「早安，幸存者」。

想快速展示角色，用即时试玩；想录完整闭环，用只响一次的大型犬。其他角色的整夜体验包含多次响铃，时长取决于设定时间和操作速度。

## 工程说明

`index.html` 保留原来的手绘引擎、音频兜底和状态逻辑，`theme.css` 定义视觉和响应式布局。四份真实录音的授权见 [CREDITS.md](CREDITS.md)。蚊子与告警由 Web Audio 合成。

响铃计划按角色与目标时间缓存，窗口尺寸改变或刷新预览不会重新随机。后台补触发合并为一次。切换角色会停止旧声音；退出任务会清理事件监听；退出或完成整夜体验后清除虚拟时间。

### 文件与部署

```text
wake-up-call/
├── index.html       # 页面、手绘角色、闹钟和交互逻辑
├── theme.css        # 视觉主题与响应式布局
├── assets/          # 新生儿、猫、公鸡、狗的四份录音
├── CREDITS.md       # 音频来源、作者、授权及剪辑说明
└── README.md
```

仓库的 GitHub Pages 工作流直接复制 `index.html`、`theme.css`、`assets/` 和 `CREDITS.md` 到 `dist/wake-up-call/`，无需安装依赖或运行构建。ZIP、`minitool/` 容器副本和本地辅助脚本不纳入仓库与部署产物。
